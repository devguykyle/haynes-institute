# Start Here

The Haynes Institute is being built as a plain, durable library for theology, American history, and classical education.

The first goal is simple: gather sources that deserve to be read, taught, and remembered. That includes sermons by Lemuel Haynes, Jupiter Hammon's address to the Black people of New York, old AME catechisms, and historical accounts of men and women whose lives strengthened churches, schools, families, and civic life.

## How to Use the Site

- Browse the resource library for primary sources and historical entries.
- Read guides for introductions, teaching paths, and family study.
- Return often as texts, notes, and collections are added.

## Editorial Commitments

- Primary sources should be clearly identified.
- Historical claims should be sourced.
- Disputed questions should be named honestly.
- The work should serve readers, teachers, churches, families, and students.
