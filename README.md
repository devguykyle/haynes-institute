# The Haynes Institute

A Jekyll site for cataloging resources in theology, American history, and classical education, with special attention to Black American historical memory and primary sources.

## Local Development

Install dependencies:

```powershell
bundle install
```

Run the site:

```powershell
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

## GitHub Pages

This project uses the `github-pages` gem for compatibility. Push the repository to GitHub, then enable Pages in the repository settings.
